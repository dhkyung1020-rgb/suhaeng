# 수행평가 제출함

학생이 **학번 · 이름 · 파일**을 올리면 구글 드라이브의 수행평가 폴더에 `학번_이름.확장자`로 저장되는 웹앱입니다.
수행평가마다 폴더를 하나씩 만들어 계속 재사용할 수 있습니다.

- 화면(학생·관리자): **GitHub Pages**
- 서버(드라이브 저장): **Google Apps Script**

```
내 드라이브/2026 기술가정/
 ├─ 수행평가 제출기록 (스프레드시트: 제출 시각·학번·이름·파일 링크)
 ├─ 소비생활 홍보자료/
 │    ├─ 20101_홍길동.pdf
 │    └─ 20102_김철수.pptx
 └─ (다음 수행평가 폴더…)
```

## 현재 설정

- 기준 폴더: 내 드라이브 › `2026 기술가정` (`Code.gs`의 `CONFIG.ROOT_FOLDER_ID`)
- 이 폴더 안의 하위 폴더 중 **관리자 페이지에서 만든 것(또는 '다시 열기'한 것)만** 학생에게 보입니다.

## 1. Apps Script 설정 (10분)

1. [script.google.com](https://script.google.com) → **새 프로젝트**
2. `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs`를 통째로 붙여넣기 → 저장
3. (선택) 왼쪽 ⚙️ **프로젝트 설정** → "appsscript.json 표시" 체크 → `apps-script/appsscript.json` 내용으로 바꾸기 (시간대를 서울로 맞춤)
4. 위쪽 함수 목록에서 **`setup`** 선택 → **실행** → 권한 허용
   - "확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동** (본인이 만든 스크립트라 괜찮습니다)
5. 아래 **실행 로그**에서 `관리자 비밀번호`를 확인해 두세요
   - 바꾸려면: ⚙️ 프로젝트 설정 → **스크립트 속성** → `ADMIN_PASSWORD` 값 수정
6. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙️ **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**
7. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

> ⚠️ **학교 구글 계정(Workspace)** 은 관리자가 "모든 사용자" 공개를 막아 둔 경우가 있습니다.
> 배포 옵션에 "모든 사용자"가 없으면 **개인 Gmail 계정**으로 만들거나 학교 정보부에 문의하세요.
> (학생은 로그인할 필요가 없습니다.)

## 2. GitHub Pages 설정 (5분)

1. GitHub에서 새 저장소 만들기 (예: `suhaeng`) → 이 폴더의 파일을 모두 올리기
2. `config.js`를 열어 `SCRIPT_URL`에 위에서 복사한 URL 붙여넣기 → 커밋
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/suhaeng/` 접속
   - 학생 페이지: `.../suhaeng/`
   - 관리자 페이지: `.../suhaeng/admin.html`

## 3. 사용하기

**새 수행평가 만들기**
관리자 페이지 → **+ 새 수행평가** → 이름·마감 일시·안내 문구 입력 → 드라이브에 같은 이름의 폴더가 생깁니다.
드라이브에서 직접 만든 폴더는 관리자 페이지에 '마감'으로 보이며, **다시 열기**를 누르면 학생 화면에 나타납니다.

**학생에게 안내하기**
**학생 링크 복사**를 누르면 해당 수행평가가 미리 선택된 링크(`...?a=폴더ID`)가 복사됩니다. 클래스룸·QR코드로 공유하세요.

**마감 / 다시 열기**
마감 일시가 지나면 자동으로 닫히고, **마감하기** 버튼으로 언제든 닫을 수 있습니다. 닫힌 수행평가는 학생 목록에서 사라집니다.

**제출 현황 · 미제출자**
**N개 보기** → 제출한 학생 목록. 아래 "미제출자 확인하기"에 반 학번 목록을 붙여넣으면 안 낸 학생을 바로 보여 줍니다.

**재제출**
같은 학번·이름으로 다시 내면 이전 파일은 드라이브 **휴지통**으로 옮겨지고 새 파일로 바뀝니다(30일 안에 복구 가능).
이전 파일을 남기고 싶으면 `Code.gs`의 `OVERWRITE_ON_RESUBMIT`을 `false`로 바꾸세요.

## 설정 바꾸기

`apps-script/Code.gs` 맨 위 `CONFIG`:

| 항목 | 기본값 | 설명 |
|---|---|---|
| `MAX_FILE_MB` | 2048 | 파일 1개 최대 용량(MB). 학생 브라우저가 드라이브로 직접 올리므로 영상도 가능 |
| `MAX_FILES` | 5 | 한 번에 올릴 수 있는 파일 수. 여러 개면 `학번_이름_1.pdf`, `학번_이름_2.pdf` |
| `STUDENT_ID_PATTERN` | 숫자 4~6자리 | 학번 형식 |
| `OVERWRITE_ON_RESUBMIT` | true | 재제출 시 이전 파일을 휴지통으로 |

드라이브 무료 용량(15GB)이 차면 업로드가 실패하니, 영상 과제는 남은 용량을 확인하세요.

용량·개수를 바꿨다면 `config.js`의 같은 값도 맞춰 주세요.

**Code.gs를 고친 뒤에는** 배포 → **배포 관리** → ✏️ 수정 → 버전: **새 버전** → 배포 해야 반영됩니다. (URL은 그대로 유지)

## 파일 구성

```
index.html            학생 제출 페이지
admin.html            선생님 관리 페이지
config.js             Apps Script URL 설정
common.js             공통 함수 (서버 통신 등)
style.css             디자인
apps-script/Code.gs   Apps Script 서버 코드 (script.google.com에 붙여넣기)
apps-script/appsscript.json
```

## 참고

- 파일은 배포한 선생님 계정의 드라이브에 저장됩니다. 학생은 드라이브 폴더를 볼 수 없습니다.
- 관리자 비밀번호는 서버(스크립트 속성)에만 저장되며 GitHub에는 올라가지 않습니다.
- Apps Script 무료 계정 기준 하루 실행 시간 등 할당량이 있지만, 한 학교의 수행평가 제출 정도는 충분합니다.
